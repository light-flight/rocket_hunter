# Rocket Hunter

PWA для менеджера картинговой команды: помогает отслеживать, какая машина стоит на выходе
из пит-коридора. Работает без сети и синхронизируется с сервером, когда связь появляется.

Сейчас в репозитории только каркас: экран-заглушка с проверкой связи, готовности к работе
без сети и временной проверкой локального хранилища.

## Устройство

- **Сервер** — Rails 8.1 + PostgreSQL, отдаёт только JSON под `/api`.
- **Клиент** — React + TypeScript + Vite в `frontend/`. Сборка копируется в `public/`,
  и Rails раздаёт её как статические файлы с корня сайта. Статические файлы сайта кладутся
  в `frontend/public/`: каталог `public/` очищается при каждой сборке, в нём сохраняются
  только файлы Rails, перечисленные в `.gitignore`.
- **Офлайн** — `vite-plugin-pwa` кэширует приложение на телефоне, данные лежат в IndexedDB (Dexie).

## Запуск

Нужны [mise](https://mise.jdx.dev) (версии Ruby и Node в `mise.toml`) и Docker.

```bash
mise install
bin/setup
```

`bin/setup` ставит зависимости, поднимает PostgreSQL из `compose.yaml` (порт 5433),
создаёт базы и запускает `bin/dev`: Rails на порту 3000 и Vite на 5173.
Приложение при разработке открывается по адресу http://localhost:5173.
Если mise не активирован в оболочке, запускайте команды через `mise exec -- ...`.

В режиме разработки service worker выключен. Чтобы проверить работу без сети,
соберите приложение в `public/` и откройте его через Rails по адресу http://localhost:3000:

```bash
npm --prefix frontend run build:rails
```

## Проверка на телефоне

Нужен выложенный сервер с HTTPS: без него service worker на телефоне не работает.

1. Открыть адрес приложения в браузере и добавить на экран «Домой».
2. Открыть приложение **с иконки при наличии сети** и дождаться «Работа без сети: готово».
   На iPhone у приложения с иконки своё хранилище, отдельное от Safari: то, что было
   закэшировано или записано во вкладке Safari, в него не переходит.
3. Нажать «Записать» несколько раз, включить авиарежим, закрыть приложение и открыть снова:
   приложение открывается, число записей сохранилось.
4. Перезагрузить телефон, открыть приложение без сети: записи на месте.
5. Вернуть сеть, выложить новую сборку, вернуться в открытое приложение: появляется кнопка
   обновления, после нажатия строка «Сборка» внизу меняется.

## Проверки

```bash
bin/ci
```

Запускает RuboCop, Brakeman, тесты Rails, линтер клиента и сценарий Playwright,
который открывает собранное приложение через Rails, отключает сеть и проверяет,
что оно открывается и хранит записи.

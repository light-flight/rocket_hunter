# Rocket Hunter

PWA для менеджера картинговой команды: помогает отслеживать, какая машина стоит на выходе
из пит-коридора. Работает без сети и синхронизируется с сервером, когда связь появляется.

Сейчас в репозитории только каркас: экран-заглушка с проверкой связи, готовности к работе
без сети и временной проверкой локального хранилища.

## Устройство

- **Сервер** — Rails 8.1 + PostgreSQL, отдаёт только JSON под `/api`.
- **Клиент** — React + TypeScript + Vite в `frontend/`. Сборка копируется в `public/`,
  и Rails раздаёт её как статические файлы с корня сайта.
- **Офлайн** — `vite-plugin-pwa` кэширует приложение на телефоне, данные лежат в IndexedDB (Dexie).

## Запуск

Нужны [mise](https://mise.jdx.dev) (версии Ruby и Node в `mise.toml`) и Docker.

```bash
mise install
bin/setup
```

`bin/setup` ставит зависимости, поднимает PostgreSQL из `compose.yaml` (порт 5433),
создаёт базы и запускает `bin/dev`: Rails на порту 3000 и Vite на 5173.
Приложение при разработке открывается по адресу http://localhost:5173.

В режиме разработки service worker выключен. Чтобы проверить работу без сети,
соберите приложение в `public/` и откройте его через Rails:

```bash
npm --prefix frontend run build:rails
```

## Проверки

```bash
bin/ci
```

Запускает RuboCop, Brakeman, тесты Rails, линтер клиента и сценарий Playwright,
который открывает собранное приложение через Rails, отключает сеть и проверяет,
что оно открывается и хранит записи.
